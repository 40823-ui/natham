ปริพันธ์

ปริพันธ์ (Integral) เป็นอีกหนึ่งแนวคิดสำคัญ ของแคลคูลัส ใช้สำหรับหาพื้นที่ใต้กราฟ และหาปริมาณที่เกิดจากการสะสม


ตัวอย่างสูตรปริพันธ์ของ x ยกกำลัง n คือ


∫ xⁿ dx = xⁿ⁺¹ / (n+1) + C


ตัวอย่างเช่น ปริพันธ์ของ x² คือ


∫ x² dx = x³ / 3 + C


ปริพันธ์สามารถนำไปใช้หาพื้นที่ ปริมาตร ระยะทาง และปริมาณสะสมต่าง ๆ ได้
